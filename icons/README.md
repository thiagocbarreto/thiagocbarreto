# Icons

You'll need to add icon files here:

- `icon16.png` - 16x16 pixels
- `icon48.png` - 48x48 pixels  
- `icon128.png` - 128x128 pixels

These should be PNG files with transparent backgrounds.

For now, you can use any simple 🎯 target icon or YouTube-related icon for testing.

You can create these icons or use online icon generators like:
- https://favicon.io/
- https://iconifier.net/
- Or any PNG icon with the target/focus theme
